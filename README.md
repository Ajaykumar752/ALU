# 4-Bit Arithmetic Logic Unit (ALU) using Verilog HDL

## 🚀 Project Overview

This project implements a **4-bit Arithmetic Logic Unit (ALU)** using Verilog HDL.

The ALU performs 16 different arithmetic and logical operations based on a 4-bit selection input (`alu_sel`).

The design is written in Verilog and simulated using Xilinx Vivado.

## ⚙️ Features

- 4-bit input operands (A and B).
- 4-bit operation selection input.
- 16 different arithmetic and logical operations.
- 4-bit and 8-bit multiplication.
- Comparison and reduction operations.
- Left and right shift operations.
- Testbench-based functional verification.

## 🛠️ Tools & Technologies

- Verilog HDL
- Xilinx Vivado
- RTL Design
- Functional Simulation
